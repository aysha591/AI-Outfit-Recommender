
# AI Outfit Recommender

## Project Description
AI Outfit Recommender is a Python-based application that suggests outfits according to the user's preferences.

## Features
- Occasion-based recommendations
- Weather-based outfit selection
- Favourite colour selection
- Clothing style selection
- Top 3 matching outfit suggestions

## Technologies Used
- Python
- Pandas
- Streamlit
- GitHub

## How It Works
The application compares user preferences with an outfit dataset and recommends the three outfits with the highest matching scores.
